# StripWolf.Core.Tests

Automated tests for `StripWolf.Core` (xUnit v3, .NET 10). The platform specific parts are replaced by small
hand-written fakes:

| Real implementation | Replaced by | Why |
|---|---|---|
| PDFium renderer (`StripWolf.Desktop`) | `FakePdfRenderer` | lives in the desktop executable, returns pre-made JPEG pages |
| WebView2 / WPE pagination (`StripWolf.Desktop`) | `FakeWebViewPaginationService` | one page per chapter (configurable), records the HTML it got |
| Komga server | `FakeKomgaServer` (HttpMessageHandler) | via the internal `KomgaApiService(Func<HttpMessageHandler>)` constructor |
| Komga server for `KomgaSyncService` | `LoopbackHttpServer` (127.0.0.1, random port) | `KomgaApiServiceFactory` creates its own `KomgaApiService` |

All services that store data get a per-test temporary directory (`TempDirectory`, `TestServiceHost`) through their
internal constructors, so the tests never touch the real settings, database or library and can run in parallel.

## Running

```shell
# everything that runs in CI
dotnet test src/StripWolf/StripWolf.Core.Tests/StripWolf.Core.Tests.csproj --filter "Category!=LocalComics"

# a single class / test
dotnet test src/StripWolf/StripWolf.Core.Tests/StripWolf.Core.Tests.csproj --filter "FullyQualifiedName~ComicReaderServiceTests"
```

The test project is an executable (xUnit v3), so `dotnet run --project src/StripWolf/StripWolf.Core.Tests` works too.

`StripWolf.Core` is built without OpenCV for the tests (`UseOpenCvPanelDetection=false`, nothing needs the panel
detection and the native runtime isn't available on Linux CI). In a full solution build on Windows `StripWolf.Desktop`
builds `StripWolf.Core` with OpenCV, pass `-p:UseOpenCvPanelDetection=true` to the tests if both should share one
`StripWolf.Core` build.

Notes:
- `KomgaSyncServiceTests` talk HTTP to `127.0.0.1`. If you have `HTTP_PROXY`/`HTTPS_PROXY` set, add `127.0.0.1` to
  `NO_PROXY`.
- `Infrastructure/TestAssemblySetup.cs` redirects `StripWolf.Core.Services.Logger` to a file in the temp folder
  (`Logger.RedirectTo`), so errors logged by the services under test never end up in the real `stripwolf.log`.
- `UiProgressThrottle` is not tested: it dispatches through Avalonia's `Dispatcher.UIThread`, which needs a running
  Avalonia application.
- ImageSharp 4 checks its license at build time only for projects referencing it directly. The tests use it
  transitively (like `StripWolf.Desktop`); the csproj still passes `StripWolf.Core/sixlabors.lic` as
  `SixLaborsLicenseFile` in case a direct reference is ever added.

## Categories

| Category | Content | CI |
|---|---|---|
| *(none)* | tests with the synthetic fixtures in `TestData` | yes |
| `LocalComics` | the developer's own comics, see below | no (`--filter "Category!=LocalComics"`) |

Tests documenting known bugs are marked with `Skip = "Known bug: ..."`; remove the `Skip` when the bug is fixed.

## Local comic tests

Real comics can't be committed (copyright), so `LocalComicsTests` reads them from a folder given by the environment
variable `STRIPWOLF_TEST_COMICS` (searched recursively for `.cbz .cbr .cb7 .cbt .pdf .epub`). Every file becomes one
test case for each check:

- all pages can be read and decode as an image (`Image.Identify`, AVIF is only checked for content)
- the import analysis (page count, cover) matches the reader
- CBR/CB7/CBT convert to CBZ with identical pages (and ComicInfo)
- ComicInfo.xml is parsed when present and survives a write/read round trip
- EPUBs convert with the fake WebView (real parsing, resource extraction and HTML sanitizing)

PDFs are skipped for the page checks: PDFium is part of `StripWolf.Desktop`.

```powershell
# PowerShell
$env:STRIPWOLF_TEST_COMICS = "D:\Comics"
dotnet test src/StripWolf/StripWolf.Core.Tests/StripWolf.Core.Tests.csproj --filter "Category=LocalComics"
```

```shell
# bash
STRIPWOLF_TEST_COMICS=~/Comics dotnet test src/StripWolf/StripWolf.Core.Tests/StripWolf.Core.Tests.csproj --filter "Category=LocalComics"
```

Without the variable the tests are reported as skipped. The file list is determined during test discovery: restart
the test run (or the IDE's test explorer) after changing the variable.

## Test data

`TestData` contains small synthetic comics (~200 KiB in total) generated by `TestData/generate_fixtures.py`:
four numbered pages (`page1.jpg`, `page2.png`, `page3-4.jpg` as a double page spread, `page10.jpg` to test the natural
sort) stored in a scrambled order, plus `Thumbs.db`, `notes.txt` and `__MACOSX/._page1.jpg` which must be ignored.

| File | Content |
|---|---|
| `comic_with_info.cbz` / `comic_no_info.cbz` | ZIP with / without ComicInfo.xml |
| `comic_subfolders.cbz` | pages in `ch2/` and `ch10/` |
| `comic.cbt` | TAR |
| `comic.cb7` / `comic_solid.cb7` | 7-Zip non-solid / solid |
| `comic.cbr` / `comic_solid.cbr` | RAR5 non-solid / solid |
| `comic.pdf` | the pages as PDF (only used as file, the renderer is faked) |
| `comic.epub` | fixed layout EPUB 3, one image per page, cover image, nav + NCX, unsafe markup in page 2 |
| `pages/` | the source pages, the tests compare the extracted bytes with these |

To regenerate them (Python 3.9+, Pillow >= 10.1, img2pdf, and `7z` and `rar` on the PATH):

```shell
pip install pillow img2pdf
cd src/StripWolf/StripWolf.Core.Tests/TestData
python3 generate_fixtures.py
```

The page JPEGs/PNGs change with every regeneration (encoder versions), so commit the archives and `pages/` together.
